# Colaboradores e Distribuição Automática

> Configure colaboradores para distribuição automática dos valores arrecadados.

# Configurando colaboradores

O Setup Digital permite distribuir automaticamente parte dos valores arrecadados para colaboradores cadastrados.

## Cadastrando colaboradores

Acesse:

```text
Cobranças -> Comissionamento
```

![Menu de comissionamento das cobranças](/images/setup-digital/menu-comissionamento.png)

Clique em:

```text
Adicionar colaborador
```

![Tela de cadastro de colaborador](/images/setup-digital/adicionar-colaborador.png)

Informe:

* nome;
* CPF;
* e-mail;
* dados bancários.

## Validação cadastral

Cada colaborador deverá realizar sua validação biométrica.

![Menu de ações para cadastrar biometria do colaborador](/images/setup-digital/biometria-colaborador.png)

Após aprovação, estará apto a receber automaticamente os valores.

## Configurando a distribuição

Ao criar uma nova cobrança, utilize a seção:

```text
Comissionamento
```

![Seção de comissionamento na criação de nova cobrança](/images/setup-digital/configurar-comissionamento-cobranca.png)

Selecione um ou mais colaboradores e defina o percentual destinado para cada um.

![Colaboradores selecionados para comissionamento](/images/setup-digital/colaboradores-selecionados-cobranca.png)

Após a confirmação do pagamento, a plataforma realizará automaticamente toda a distribuição.
