# Guia visual de comissionamento

<Info>
  Este guia apresenta o fluxo visual para acessar o menu de Comissionamento, cadastrar colaboradores, iniciar a biometria e selecionar colaboradores durante a criação da cobrança.
</Info>

## Fluxo apresentado no guia

<Steps>
  <Step title="Acessar o menu de Comissionamento">
    Acesse a aba de Comissionamento no menu de Cobranças para visualizar, gerenciar e cadastrar colaboradores.
  </Step>

  <Step title="Adicionar colaboradores">
    Cadastre as informações pessoais e bancárias do colaborador que receberá parte do valor da cobrança.
  </Step>

  <Step title="Cadastrar biometria">
    Utilize o menu de ações do colaborador para iniciar o cadastro de biometria.
  </Step>

  <Step title="Configurar o comissionamento">
    Durante a criação da cobrança, selecione os colaboradores que receberão o percentual definido.
  </Step>
</Steps>
