# Primeiros Passos

Antes de utilizar o Setup Digital pela primeira vez, é necessário realizar uma configuração inicial da imobiliária.

## Requisitos

Antes de iniciar, confirme que:

* você possui perfil de Administrador no Painel Lado Bom;
* os dados cadastrais da imobiliária estão atualizados;
* existe uma conta bancária cadastrada para recebimento dos repasses.

## Etapa 1 - Configurar os dados bancários

Acesse:

```text
Painel Lado Bom -> Dados Cadastrais -> Dados Bancários
```

Cadastre a chave PIX da imobiliária.

Essa conta será utilizada para recebimento dos valores processados pela plataforma.

## Etapa 2 - Ativar a funcionalidade

Acesse:

```text
Administrativo -> Cobranças
```

Na primeira utilização será exibida a tela de ativação.

![Tela de ativação da ferramenta de cobranças](/images/setup-digital/ativacao-cobrancas.png)

<Steps>
  <Step title="Confira as informações">
    Revise os dados apresentados para a imobiliária.
  </Step>

  <Step title="Confirme os dados">
    Confirme que as informações estão corretas.
  </Step>

  <Step title="Ative a funcionalidade">
    Clique em "Ativar funcionalidade".
  </Step>
</Steps>

## Etapa 3 - Validar a conta

Para garantir segurança nas operações financeiras, será necessário realizar uma validação cadastral.

A validação é realizada através de biometria facial.

Basta:

* escanear o QR Code;
* ou utilizar o link disponibilizado.

![Tela de validação biométrica da ferramenta de cobranças](/images/setup-digital/biometria-cobrancas.png)

Após aprovação, a funcionalidade estará disponível.
